# ВАЖНО: демонстрационные данные

Файлы в этой папке содержат **синтетические придуманные данные**, чтобы показать структуру и проверить связи. Это НЕ исходные данные ДЭ от преподавателя и НЕ следует выдавать их за оригинальный импорт.

Созданы строки в требуемых количествах: categories 2, manufacturers 6, suppliers 2, products 30, roles 3, users 10, pvz 36, orderstatus 2, orders 10, prodorders 20. Логины и пароли пользователей тестовые (demo1…demo10 / demo-pass-1…demo-pass-10).

Перед сдачей замени эти CSV на данные из четырёх исходных Excel преподавателя, затем пересоздай data.sql из своей реальной базы и проверь ER-модель.
