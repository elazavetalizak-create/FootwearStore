# FootwearStore — учебный проект базы данных

Репозиторий для материалов практических занятий по проекту магазина обуви.

## Состав
- `db/create_v1.sql` — черновой скрипт создания 10 таблиц MySQL.
- `db/queries.sql` — запросы каталога, поиска, фильтрации, сортировки и CRUD.
- `db/checks.sql` — контроль количества строк и связей после импорта.
- `db/import_templates/` — CSV-шаблоны с заголовками.
- `submission_checklist.md` — список проверок перед сдачей.
- `НУЖНО_ДОБАВИТЬ.txt` — перечень отсутствующих исходных материалов.

## Важно
Это загруженный черновой комплект, а не полностью готовая сдача. CSV в папке шаблонов содержат только заголовки, а не данные. Файл `data.sql` не включён, потому что его нужно экспортировать из реально заполненной базы. Структуру `create_v1.sql` необходимо сверить с моделью MySQL Workbench (.mwb).

## Порядок работы
1. Заполнить CSV исходными данными из выданных Excel.
2. Сверить структуру и внешние ключи с ER-моделью.
3. Выполнить `db/create_v1.sql`, импортировать CSV.
4. Выполнить `db/checks.sql` и проверить результаты.
5. Экспортировать реальные данные в `data.sql`.
6. Проверить восстановление базы и запросы приложения.
7. Добавить ER-диаграмму, отчёт и диаграмму Гантта после обновления.

Не загружайте шаблоны CSV как будто это заполненные исходные данные.
