# FootwearStore — учебный проект базы данных

Проектная основа информационной системы магазина обуви (MySQL 8.0+).

## Состав репозитория
- `db/create_v1.sql` — проектная схема десяти таблиц.
- `db/queries.sql` — авторизация, каталог, поиск, фильтр, сортировка, CRUD.
- `db/checks.sql` — контроль количества строк и внешних ссылок.
- `db/data_demo.sql` — синтетические демонстрационные записи, НЕ оригинальный экспорт.
- `db/import_demo/` — десять CSV с синтетическими демонстрационными данными.
- `docs/er_diagram.mmd` — текстовая ER-диаграмма, согласованная с проектной схемой.
- `docs/STATUS_И_ДАЛЬШИЕ_ШАГИ.md` — статус и список оставшихся действий.

## Важно перед сдачей
Этот репозиторий содержит подготовленный учебный черновик, но пока не подтверждённую финальную работу. Данные придуманы для демонстрации и не получены из исходных Excel преподавателя. Структура SQL не сверена с моделью .mwb, запуск запросов и восстановление базы не подтверждены. `data_demo.sql` не является экспортом `data.sql` из реально заполненной базы.

Для финальной сдачи необходимо заменить демо-данные оригинальными, сверить схему с .mwb, проверить SQL в MySQL, экспортировать настоящий data.sql, добавить исходный отчёт с актуальной ER-диаграммой и заполнить Гантт по фактическим результатам.

## Быстрый запуск демонстрации
В MySQL Workbench выполнить по порядку:
1. `db/create_v1.sql`
2. `db/data_demo.sql`
3. `db/checks.sql`

Использовать только отдельную тестовую схему. Не применять демо-пароли в рабочей системе.
