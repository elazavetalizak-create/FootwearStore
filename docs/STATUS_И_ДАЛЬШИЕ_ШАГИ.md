# Состояние проекта FootwearStore

## Что подготовлено
- Проектная схема из 10 таблиц в `db/create_v1.sql`.
- Запросы авторизации, каталога, поиска, фильтрации, сортировки и CRUD в `db/queries.sql`.
- Контрольные запросы в `db/checks.sql`.
- Демонстрационные CSV в `db/import_demo/` и синтетический SQL seed `db/data_demo.sql`.
- Текстовая ER-диаграмма в `docs/er_diagram.mmd`.

## Ограничения
Данные вымышленные и не импортированы из исходных Excel. Структура не сверена с файлом MySQL Workbench (.mwb). Запуск SQL в MySQL и восстановление базы не подтверждены. Поэтому `data_demo.sql` нельзя считать требуемым экспортом `data.sql` из заполненной БД.

## Перед итоговой сдачей
1. Заменить CSV данными из четырёх исходных Excel.
2. Сверить таблицы, поля, типы и внешние ключи с .mwb.
3. Выполнить создание и импорт в MySQL Workbench.
4. Запустить `db/checks.sql` и проверить результаты.
5. Проверить запросы приложения и операции CRUD.
6. Экспортировать настоящий `data.sql` из заполненной базы и проверить восстановление в пустую схему.
7. Вставить ER-диаграмму, экспортированную из MySQL Workbench, в исходный отчёт.
8. Заполнить диаграмму Гантта по реально выполненным этапам.
